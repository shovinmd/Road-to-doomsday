# 🎬 ROAD TO DOOMSDAY — Marvel Multiverse Watchlist

An interactive, dark-mode cinematic watchlist application for tracking your journey through the entire Marvel Multiverse leading up to **Avengers: Doomsday** (December 18, 2026).

![Road to Doomsday Preview](doomsday_preview.png)

## ✨ Features

- **⏳ Live Countdown Timer**: Dynamic real-time countdown to December 18, 2026 (`DAYS : HOURS : MINUTES : SECONDS`).
- **🎯 105 Complete Marvel Multiverse Titles**:
  - MCU — Infinity Saga (1 - 23)
  - MCU — Multiverse Saga (24 - 38)
  - MCU — Important Supporting Stories (39 - 52)
  - X-Men / Fox Universe (53 - 64)
  - Fantastic Four — Other Universes (65 - 67)
  - Tobey Maguire Spider-Man Universe (68 - 70)
  - Andrew Garfield Spider-Man Universe (71 - 72)
  - Sony Spider-Man Universe (73 - 78)
  - Spider-Verse Animated (79 - 80)
  - Marvel Animated / Multiverse (81 - 83)
  - Marvel Television / Defenders (84 - 96)
  - Other Marvel Universes (97 - 101)
  - Extra Multiverse Preparation (102 - 105)
- **🏷️ Importance Level Badges**:
  - 🔴 **ESSENTIAL**: Directly useful for understanding Doomsday
  - 🟡 **IMPORTANT**: Strongly connected to characters/universes
  - ⚪ **OPTIONAL**: Helps understand wider Marvel universes
- **🔎 Where to Watch Streaming Guide**: One-click Google search for legal streaming options.
- **🚀 Dynamic Progress & Journey Milestones**: Track your progress with animated nodes (`Started` ➔ `12 Watched` ➔ `Multiverse Unlocked` ➔ `X-Men Done` ➔ `Spider-Verse Done` ➔ `DOOMSDAY READY`).
- **💾 Automatic Browser Saving**: Progress is saved automatically in `localStorage`.
- **📱 Fully Responsive Design**: Mobile-friendly 2x2 countdown grid and large touch-enabled checkboxes.

## 🚀 Quick Start

Open `index.html` in any modern browser, or run locally:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
